# Evidence handling

Evidence groups EV-001 through EV-007 contain the supporting AWS console captures, scanner outputs and source references for T-01 through T-07. The evidence register records file paths, provenance, known collection dates and technical source limitations. Collection dates remain unspecified where the source does not establish them.

Screenshots, raw scanner exports and session documents require controlled access. They include infrastructure identifiers, subscriber details and historical presigned-URL credential metadata. The repository publishes audit documentation, CSV assessment tables and the reviewed architecture diagrams. Git excludes raw scanner bundles, console screenshots and session DOCX files; those originals remain in the local audit record.

The same identity capture supports EV-006 and EV-007 and represents one source artifact. The earlier and final Prowler runs are distinct assessments. RDS capacity, Vocareum restart and WSL incidents have narrative support without primary captures. The application session-expiry image does not establish AWS Academy expiry. See the [evidence limitations](../14_Appendices/Evidence_Gaps_and_Interpretation.md).
