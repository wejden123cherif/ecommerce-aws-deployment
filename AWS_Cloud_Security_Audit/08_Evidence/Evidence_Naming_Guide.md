# Evidence reference conventions

Tests use identifiers T-01 through T-07 and filenames such as `T01_Cloud_Governance.md`. Evidence groups EV-001 through EV-007 correspond to those tests. Capture references use the group prefix and sequence, such as `EV002-01`.

Scanner captures use `EV006-P01` through `EV006-P03` for Prowler and `EV006-S01` through `EV006-S08` for ScoutSuite. The application-context capture `APP-01` is separate from the technical evidence groups.

Artifact filenames in group indexes refer to the private evidence record. Raw scanner reports retain their accompanying assets and run timestamps so results can be interpreted in the context of the correct run.
