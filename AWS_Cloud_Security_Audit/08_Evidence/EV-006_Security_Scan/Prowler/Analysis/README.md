# Scanner analysis

[Prowler dispositions](Prowler_Failed_Results_Disposition.csv) account for all 111 FAIL rows by check, raw finding and resource identifier, source severity, audit finding ID, disposition and reason.

An empty audit finding ID means that a scanner observation was not promoted to a separate audit finding. It does not establish resolution or compliance. Reasons distinguish shared root causes, platform ownership, permission ambiguity and additional hardening needs. Scanner severity is separate from the audit risk rating.

[Scanner comparison](Scanner_Comparison.csv) records corroboration and coverage limits. Fourteen Prowler MANUAL rows and ScoutSuite collection errors qualify assurance. The raw outputs, manual captures and Critical/High extraction provide the underlying technical evidence.
