# Audit programme

The programme defines seven tests against the scope established on 9 October 2026. Session 1 documents the scope, responsibilities, architecture and initial evaluation grid; Session 2 records technical execution.

Wejden Cherif and Maram Raboudi form the audit team, supervised by Mohamed Ali Hadhri. The team assesses application configuration and records evidence. AWS Academy/Vocareum manages lab permissions and platform constraints.

The [traceability matrix](Final_Traceability_Matrix.csv) maps each criterion and ISO control to its test, evidence group, result and finding. [Test records](../07_Audit_Tests/README.md) document execution, and the [findings register](../10_Audit_Findings/Findings_Register.csv) defines F-01 through F-10.
