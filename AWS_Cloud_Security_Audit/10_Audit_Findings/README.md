# Audit findings

The [findings register](Findings_Register.csv) defines ten findings, F-01 through F-10, with evidence references, ratings and recommendations. [Detailed findings](Findings_Detailed.md) explain the technical basis. The [disposition register](Findings_Disposition.csv) records how scanner observations were assessed.

F-01 (Internet-wide SSH) and F-02 (unencrypted EBS) are Major / High; F-03 (Cognito MFA not enforced) is Minor / Medium. F-04 through F-10 are hardening observations. Scanner severity and audit risk are recorded separately; multiple check-resource failures may support one finding.
